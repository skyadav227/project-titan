# Interview Module - User Flow

## User Journey Map

### Flow 1: Start Mock Interview

```
User Dashboard
    ↓
Browse Interview Categories
    ↓
Select Role/Difficulty Level
    ↓
Review Interview Settings
    ↓
Start Interview Session
    ↓
Receive Question
    ↓
Record Response
    ↓
Submit Answer
```

### Flow 2: Interview Progress

```
Question Asked (Text/Audio)
    ↓
User Answers (Text/Speech)
    ↓
Real-time Transcription
    ↓
Timer Display
    ↓
Next Question or Completion
```

### Flow 3: Review Results

```
Interview Complete
    ↓
AI Evaluation Processing
    ↓
View Overall Score
    ↓
Review Detailed Feedback
    ↓
Analyze Performance Metrics
    ↓
View Improvement Suggestions
```

### Flow 4: Track Progress

```
Access Interview History
    ↓
Compare Performance Over Time
    ↓
Identify Weak Areas
    ↓
Select Topic for Practice
    ↓
Start Targeted Interview
```

## Key Decision Points

- **Category Selection**: User chooses between role-based or topic-based interviews
- **Difficulty Level**: Easy, Medium, Hard, Expert
- **Response Format**: Text or Speech input
- **Retake Decision**: Option to retake interview or review results
