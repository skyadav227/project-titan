# TITAN Design System v1

## Design Philosophy

TITAN is a modern AI interview platform designed to feel premium, minimal, fast, and approachable. Every screen should feel consistent, intuitive, and professional.

### Core Principles

* Simplicity over complexity
* Consistency over creativity
* Accessibility first
* Performance matters
* Every interaction should feel intentional

## Design Inspiration

* Vercel
* Linear
* GitHub
* Notion

## Theme

* Dark mode by default
* Clean typography
* Minimal visual noise
* Subtle animations
* Modern SaaS aesthetic

## Color Palette

* Background: #0A0A0A
* Surface: #111111
* Card: #18181B
* Primary: #2563EB
* Success: #22C55E
* Warning: #F59E0B
* Error: #EF4444
* Text: #F5F5F5
* Secondary Text: #A1A1AA
* Border: #27272A

## Typography

Font Family: Inter

Hierarchy:

* Hero Heading
* Section Heading
* Subheading
* Body Text
* Caption
* Button Text

## Layout

* Maximum Content Width: 1280px
* 8-point spacing system
* Responsive design from mobile to desktop

## Border Radius

* Small: 8px
* Medium: 12px
* Large: 16px
* Pill: Full rounded

## Components

Reusable components include:

* Buttons
* Cards
* Inputs
* Navbar
* Sidebar
* Modals
* Progress Bars
* Badges
* Toast Notifications

## Motion

* Hover: 200ms
* Page Transition: 300ms
* Button Press: 100ms
* Smooth easing throughout

Animations should enhance usability, not distract from it.

## Accessibility

* Semantic HTML
* Keyboard navigation
* Visible focus states
* Sufficient color contrast
* Responsive on all devices

## Product Personality

TITAN should communicate like a knowledgeable senior developer and mentor.

It should be encouraging, direct, and practical—never robotic or overly formal.

## Engineering Standards

* Reusable components
* Clean folder structure
* Mobile-first development
* Consistent naming conventions
* Performance-conscious implementation
